# Repostería a tu ritmo

PWA general de recetas dulces de ATLAS. Reúne las colecciones anteriores sin
eliminarlas durante la transición.

## Estado del primer hito

- Las recetas de bollería y galletas están migradas con ingredientes y pasos.
- Las recetas de las PWA anteriores aparecen clasificadas y enlazadas como
  acceso provisional hasta completar su migración ficha a ficha.
- Las diez publicaciones pendientes de Instagram están inventariadas; las que
  ofrecen cantidades públicas incluyen una ficha más detallada.
- Las recopilaciones de cinco masas y ocho pasteles se conservan como
  colecciones, sin inventar las cantidades que solo aparecen en sus imágenes.
- Los buñuelos con nata están excluidos por decisión del propietario.

## Uso local

```bash
npm test
python3 -m http.server 8767 --directory dist
```

No hay compras, membresías ni recopilación de datos personales.
